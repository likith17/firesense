# Thirty-second demo plan

Target 26-29 seconds. Record actual app interactions, not simulated observations. Confirm the rendered UI first.

0-5 seconds: Open Global 2026. Say: "FireSense turns NASA satellite hotspots into an auditable burning calendar."

5-12 seconds: Select California history and show the calendar. Say: "Explore seasons, regions, and years while keeping missing data and provisional observations explicit."

12-21 seconds: Open Evaluation and the California adjusted calendar. Say: "Our experimental sensor mapping reduced held-out error thirteen percent versus a fitted ratio, across three U.S. regions."

21-28 seconds: Show the source ledger. Say: "Every result traces to NASA exports. Global historical backfill and coverage correction are next; this is not a fire forecast."

Record at a readable resolution. Keep an unobtrusive title and NASA FIRMS source credit visible. Disclose ChatGPT/Codex assistance on the project page. The final video must be measured to verify it meets the event's limit; this document is a script, not a completed video.
